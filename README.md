## 定制改动点

- **只留 VSCode 扩展**：移除 PC / Electron 端（主进程、打包配置、electron 通信通道）及对应页面与组件，只构建 `.vsix`。
- **只读本地书籍**：去掉发现、搜索、规则管理、播放器、iframe、登录等联网入口，书架只列本地 TXT / EPUB。
- **打开直达正文**：跳过封面、扉页、版权、目录等前置页，直接进入第一章正文；重新打开自动续读上次章节。
- **本章查找**：`Ctrl+F` 唤起查找栏，命中高亮并计数，Enter / Shift+Enter 前后跳转，Esc 关闭；查找栏随窗口宽度自适应。
- **全书查找**：切换「全书」后并发抓取各章正文、边搜边出结果，列出章节名与上下文片段，点结果跨章定位到第 N 处命中。
- **EPUB 注释跳转**：点正文注释链接，同章直接滚动定位，跨章自动切章并轮询等待渲染后定位；跳转后可点「返回」回退，✕ 只取消回退状态。
- **目录抽屉**：带筛选框、当前章高亮，打开时自动滚到当前章。
- **底栏入口**：目录、查找移到状态栏左侧，顶部只保留上一屏 / 下一屏，正文底部不再重复上一章 / 下一章。
