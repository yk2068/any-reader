# any-reader

在 VSCode 侧栏里读本地书：TXT / EPUB 书架、目录、全书查找。

## 功能

- **书架**：扫描本地书籍目录（设置 → 本地书籍目录），路径可带引号直接粘贴
- **直达正文**：打开书籍跳过封面、版权页、目录页，并从上次读到的章节续读
- **目录抽屉**：可筛选，当前章高亮
- **查找**：`Ctrl+F` 本章查找带命中计数，可切换全书查找，结果跨章跳转
- **注释跳转**：EPUB 注释与锚点，同章滚动、跨章定位，可一键返回
- **阅读样式**：字号、行高、字距、段落间距、配色与翻页快捷键可调

## 安装

```
code --install-extension any-reader-1.11.17.vsix --force
```

## 使用

点击活动栏的 any-reader 图标打开侧栏。底部工具栏左侧是目录与查找，右侧是书架与设置；设置再点一次即回到原来的阅读位置。

## 说明

只读本地文件，不内置书源规则。
